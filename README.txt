NCLUB — EXPERIENCIA VIP 3D · VERCEL + META QUEST 3

1. Publicar en Vercel: crea un nuevo proyecto con esta carpeta como raíz. Es un sitio HTML estático sin build.
2. Abre la URL HTTPS en un navegador moderno. En Meta Quest 3 abre Meta Quest Browser y selecciona ENTER VR.
3. PC: WASD y arrastrar mouse, 'Iniciar recorrido guiado', panel Concierge, reservas y pedidos simulados.
4. Quest: controladores para apuntar y pulsar el menú VR flotante. Stick para desplazamiento.
5. Requiere conexión a internet para descargar Three.js desde jsDelivr.
6. Los robots son recreaciones geométricas inspiradas en las fotos, no modelos oficiales ni sincronización MuJoCo.
7. Datos de reserva y pedidos son simulados; no hay backend ni cobros reales.
8. Si se abre index.html directamente puede fallar la carga de módulos (seguridad de navegador). Servir con: python -m http.server 8000 y abrir http://localhost:8000.
9. Se recomienda probar la comodidad y escala en Quest y ajustar velocidad de desplazamiento si hiciera falta.
